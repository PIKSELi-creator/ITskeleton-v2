# 💀 ITskeleton

> Облачная автоматизированная платформа для создания, рендеринга и подготовки коротких образовательных видео по Python для TikTok.

---

## 📌 О проекте

**ITskeleton** — серверное приложение, предназначенное для автоматизации производства коротких образовательных видео.

Проект объединяет в одной системе:

- создание сценариев;
- создание storyboard;
- подготовку плана монтажа;
- обработку изображений;
- обработку аудио;
- автоматический видеорендер;
- FFmpeg;
- TikTok OAuth;
- работу с TikTok API;
- хранение OAuth-токенов;
- Cloud-развёртывание;
- API для управления системой.

  ↓
СЦЕНАРИЙ
  ↓

  ↓

  ↓

  ↓

TIKTOK API
